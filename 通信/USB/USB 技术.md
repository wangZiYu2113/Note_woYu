
### 1.USB 简介

USB 技术是微软与英特尔共同成立的 USB-IF 组织共同认证的 
同时英特尔与苹果共同制定了雷电系列协议（Thunderbolt）

**雷电协议**
雷电 1/2 MiniDP 接口
雷电 3/4/5 统一使用 type-C

**USB-IF 协议**
![[Pasted image 20260831162018.png]]

1. 命名：
  已取消 3.0 系列命名规则，直接以传输速度命名接口；2.0 系列不变；
  第一代 5 Gbps 速率：USB 3.0  = USB 3.1 Gen1 = USB 3.2 Gen1 =  USB 5Gbps
  第二代 10 Gbps 速率： USB 3.1 = USB 3.1 Gen2 = USB 3.2 Gen2 = USB 10Gbps
  第三代 20 Gbps 速率 ：USB 3.2 = USB 3.2 Gen 2 x 2 = USB 20 Gbps
  4.0 系列第一代最高 40 Gbps 速率：USB 4.0 v1 =  USB 40 Gbps
  4.0 系列第二代最高 80 Gbps 速率：USB 4.0 v2 = USB 80 Gbps
  
2. **带宽** 不等于 **速度** ！图中的速度应更正为带宽；480 Mbps 理论速度为 60 MB/s ，实际为 42 MB/s 
3. **发展历程**
USB‑IF（USB 标准组织）吸收雷电 3 的技术，做成公开标准 USB 4.0。由此出现了 USB 4.0 第一代 40 Gbps 
雷电 4 实在 USB 4.0v1 的基础上做的强制认证版本，即雷电 4 相对于雷电 3 并没有带宽上的提升
后来出现 USB 4.0 第二代，雷电 5 又是在其基础上做的强制认证和升级 （80 Gbps）
4. **强制认证**
![[Pasted image 20260831171642.png]]
雷电 4/5 系列 USB 强制要求有如下功能 （部分 3.0 不支持 详情看上表）
- 必须支持固定双向带宽
- 必须支持 PCIe 显卡外接
- 必须支持 PD 和反向供电
- 必须支持 DP 视频隧道
- **[[USB线缆]]**
- 必须支持 DMA 保护
- 必须支持睡眠唤醒（3.0 不支持）
- 必须支持向下兼容

非雷电系列的 USB 协议不一定满足上述认证 允许对功能进行阉割

### 2.PCB 注意

1. 建议 USB 走线全部差分走线 等长控制 尽量减少过孔 
2. 高速信号要过孔包地
### 3.硬件接口

A 型接口：**Type-A**（最常见的方口 也成为 USB-A） Mini-A Micro-A
B 型接口：Type-B  Mini-B Micro-B 较少见 
C 型接口：**Type-C** 最主流、最前沿 满配为 24 针脚可支持所有 USB 协议

1. 其中 Type-A 口有四针脚（黑）和九针脚（蓝）版本 前者只适用于 USB 2.0 低速/全速模式，后者适用于 10 Gbps，速率更高只能使用 C 口
2. 当前 Mini 系列几乎全部淘汰
3. Micro 系列仅剩 Micro-B 系列
4. Type-B 系列几乎仅用于打印
5. **Type-C** 常见 3 种：6/16/24 针脚：其中 24 针脚为满配；16 针脚无 RxTx 四对高速差分信号线，无法实现 USB 3.0 及以上协议；6 针脚仅有 CC 配置线，只可做供电，不可传输信号（但可以通过配置 CC 引脚实现 PD 充放电）另外还有四针脚 Type-C，仅可 5 v 充电。

### 4.USB 芯片分类

按功能：
- HUB 控制器 一口扩多口 CH334
- 协议转换芯片  USB 转串口 CH340 等
- PD/充电协议芯片
- 隔离芯片 一般无法实现高速信号隔离 仅用于 USB 2.0 及以下
- E-Marker 芯片 线缆芯片 用于识别线缆
- 音频芯片

### 5.Type-C 引脚详解

![[Pasted image 20260831205056.png]]

| 引脚                | 名称                  | 功能                                         |
| ----------------- | ------------------- | ------------------------------------------ |
| A1 / B1、A12 / B12 | **GND** ×4          | 地                                          |
| A4 / B4、A9 / B9   | **VBUS** ×4         | 电源（PD 3.1 最高 48V/5A = 240W）                |
| A6 / B6           | **DP1 / DP2**       | USB 2.0 D+（两脚在插头内部短接，实际只有一对）               |
| A7 / B7           | **DN1 / DN2**       | USB 2.0 D-                                 |
| A5                | **CC1**             | 配置通道：插入/方向检测、角色协商、PD 通信（BMC）               |
| B5                | **CC2**             | 同上（未用做通信的 CC 脚当 **VCONN**，给线缆 E-Marker 供电） |
| A2 / A3           | **SSTXp1 / SSTXn1** | 高速发送差分对 1（TX1）                             |
| B10 / B11         | **SSRXn1 / SSRXp1** | 高速接收差分对 1（RX1）                             |
| B2 / B3           | **SSTXp2 / SSTXn2** | 高速发送差分对 2（TX2）                             |
| A10 / A11         | **SSRXn2 / SSRXp2** | 高速接收差分对 2（RX2）                             |
| A8 / B8           | **SBU1 / SBU2**     | 边带引脚：DP 的 AUX 通道、模拟音频                      |
