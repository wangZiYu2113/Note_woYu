控制目标：稳定输出电压 包括频率、幅值、相位等 对外表现为受控电压源
控制策略：电压外环 PR+电流内环 PR/PI 双闭环结构

### 电压外环 PR
输入：error_v =  参考电压（设定值）- 输出电压 **ev = vo* - vo** 
**注意**：这里的参考电压和输出电压都是**瞬时值**
输出：电感电流参考值 iL*

### 电流内环 PR
输入：电感电流误差值 **error_i = iL* - iL** 
输出：电感电压参考值 （upr = uL*）
配合前馈 **ubridge* = uo + uL*** 得到桥臂电压参考值（ubridge*）
注意 uo 为交流量 uo 的标量 因此 ubridge* 为交流量
在整流电路中 网侧电压（输入交流电压）可能会有波动 但总体来说是理想的 可以不加前馈；而在逆变中 网侧电压是输出电压 波动可能更大 因此前馈更加重要；在并网逆变中 网侧电压也是固定的 类似于整流 最好也加上前馈

### 归一化与调制
得到 ubridge* 后 通过 **m = ubridge* / Udc** 得到调制波
再通过单极性调制得到 PWM 占空比
