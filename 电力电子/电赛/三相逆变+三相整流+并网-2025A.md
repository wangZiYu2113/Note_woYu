# 一、三相逆变
### 1.PR/QPR 电压外环
输入：误差交流电压电压 = 参考**相电压** - 实际**相电压**
**error_v = vabc* - vabc**
**注意**：一定是相电压的误差值 若为三相三线制 需要采样两线电压再转换为相电压；若为三相四线制则可以直接采样相电压 本文用 vabc 代表 abc 三相的相电压
注意参看相电压的合成方法
注意**线转相的方法**
输出：参考线电流（= 相电流）iabc*

### 2.PR 电流内环
输入：误差电流 = 参考相电流 - 实际相电流
**error_i = iabc* - iabc**
输出：电感电压（相电压 误差值）vL
前馈：电感电压 + 输出相电压 = 桥臂电压（交流测）*vL + vabc = vbridge* *
归一化：桥臂电压除以 0.5 倍直流母线电压
