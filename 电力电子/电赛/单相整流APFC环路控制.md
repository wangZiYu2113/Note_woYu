# PI 电压外环+ PR 电流内环
## 控制流程：PI 电压外环 + PR 电流内环 + 前馈/归一化/调制
## 控制目标：
1.母线电压稳定且达到目标值
2.输入电流与输入电压同相 提高功率因数

### 电压外环 PI
输入：误差电压 = 参考电压（目标值）- 实际电压  **error_v = Vdc_ref - Vdc**
输出：参考电流（有效值）**Iref**
**注意**：
1. 实际应用中 误差电压为**参考电压**减去**反馈电压**而不是实际电压 这是因为单相整流电路中 直流母线存在 100 Hz 二倍频波动 因此要对实际电压进行**陷波**处理得到反馈电压
<mark class="hltr-cyan">陷波</mark> 对 100 HZ 频率的波形进行单独滤波 
2. PI 控制器的输入输出为标量 即误差电压和参考电路的有效值（RMS） 但是后级的电流内环要求输入为参考电流的**相量** 同时由于要求输入电流跟随电压的相位变化 将参考电流乘以单位电压相位   **i_ref = Iref * sin_theta**

### 电流内环 PR + **前馈**
输入：误差电流 = 参考电流 - 实际（输入）电流  **error_i = i_ref - i_ac**  相值 
输出：电感电压（uL） = 网侧电压（ugrid）- 桥臂电压（u_bridge）  **upr** = **uL** **标量**

**公式推导**
$$vL = vg - vbridge$$ $$L * di/dt = uL = vg - vbridge$$
输入电流由**电感电压**决定 即网侧电压和桥臂电压相减 显然网侧电压由电源决定 而桥臂电压可以通过改变开关管的**占空比 D**改变 
当 uL > 0 时 i 增大；当 uL < 0 时 i 减小；
因此 pr 输出电感电压可以控制输出电流增大/减小

**前馈**：在上述的 upr 定义下 前馈为：**vb_ref = vgrid - u_pr** 即前馈电压就是桥臂电压
也就是说 将网侧电压减去 pr 的输出得到了桥臂参考电压 这就是前馈的过程
由于理想网侧电压是正弦 因此当系统稳定时 前馈输出的波形为正弦信号 
注意：此处前馈的符号+/- 由电流定义的正方向决定 在电流由外侧流入整流器的正方形下 此处为减法

**前馈的作用**：若不使用前馈 则将 upr 直接定义为桥臂电压 此时 pr 要实时计算网侧电压预测桥臂电压 而使用前馈只需要输出电感电压即可 加速且效果更好

**PR面对的扰动**：电感和线路电阻压降、电感参数误差、**电网电压波动**、母线电压波动、开关死区和器件压降、负载变化
### 归一化和调制

前馈得到**桥臂参考电压**后 除以直流母线电压 Udc 实现归一化 范围为  \[-1 ~ 1]    
定义调制波 **m = ubridge / Udc**  即 m 的幅值范围为  \[-1 ~ 1]    
一般情况下还会进行限幅 \[ -0.95 ~ 0.95 ]
**调制原理** ：（左侧桥臂 V 1、V 2   右侧桥臂  V 3、V 4 ）
1. 双极性倍频调制：生成一个高频锯齿形载波 幅值正负 1 之间 其载波频率即为开关管开关频率
将 m 与载波幅值比较 ：m 较大时 上桥臂 V 1、V 4导通 电容充电周期；反之 则为电容放电周期
其中 V 1 V 4 同步 V 2 V 3 同步 14 23 之间互补
占空比 D = (m + 1) / 2
2. **单极性倍频** 调制：给两个桥臂相反的调制波
左桥臂参考：mA = m 右桥臂参考：mB = -m
然后各自与同一个三角载波比较：
mA 控制左侧桥臂 V 1、V 2  ；mB  控制右侧桥臂  V 3、V 4；
之所以叫倍频是因为当载波频率为 20 kHz 时 由于左右分别比较 外界看等效为 40 kHz
占空比：DA = (1 + m) / 2       DB = (1 - m) / 2

**m 明明是调制波 不断变化 为什么会出现占空比?**
载波（锯齿波）从 0 到 1 再到 0 为一个周期 这也是开关管的一个周期 因为周期时长很短 可取 m(t) 瞬间的幅值当作 m 计算出这一周期的占空比 从而设置 PWM。也就是说，PWM 占空比变化的频率也是 40 kHz
实际上，PWM 并不是与载波比较设置的 而是根据 m 计算出占空比 设置的。
