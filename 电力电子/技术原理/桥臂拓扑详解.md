## 1.桥臂电压与开关管的关系

如  [[PWM 调制技术]] 所说 当为单极性调制时 uAB 存在三种状态；当调制波为正半周时，uAB 有两种状态：Udc/0
由此可得关键数据 **uAB_avg** 由于开关管的开关状态不断切换 桥臂电压 uAB 也不断在 Udc 和 0 之间切换 因此通过 PWM 波占空比 可得其平均值 uAB_avg

## 2.桥臂电压与系统整体的关系
### 2.1 桥臂电压与电流 （假设单相整流 APFC 情景）
$vL=ug-vAB$
**$L*diL/dt=ug-uAB$ (瞬时模型)**
所以
ug > uAB  -> vL > 0    iL 向正方向增大
ug < uAB  -> vL < 0    iL 向负方向变化 （此为代数值变化 非绝对值）
ug = uAB  -> iL 基本不变

由于 uAB 高频跳变，电感电流在每个开关周期内产生高频纹波；
但在宏观上，开关频率远高于电网频率，因此可以用 uAB_avg 代替瞬时 uAB 建立平均模型
**即 $L*diL/dt=ug-uAB\_avg$ (平均模型)**
当 ug > uAB_avg 时，diL/dt > 0，iL 代数值增大；
当 ug < uAB_avg 时，diL/dt < 0，iL 代数值减小；
当 ug = uAB_avg 时，iL 近似保持不变

APFC 正是通过 PWM 改变 uAB_avg，使电感电流 iL 跟踪与电网电压 ug 同相的电流参考，从而实现功率因数校正。

### 2.2 桥臂电压与能量流向

规定 iL 从交流电源经电感流入 A 点、再从 B 点返回电源为正，则桥臂交流侧瞬时功率为：
pac = uAB · iL
uAB · iL > 0  -> AC 侧向 DC 侧传递能量，处于整流状态
uAB · iL < 0  -> DC 侧向 AC 侧传递能量，处于逆变状态
uAB = 0       -> 桥臂瞬时不传递有功功率
在单极性调制、电网电压正半周时  理想的 APFC 情况下 iL 可看作与电网电压同相的正弦电流 因此其频率远小于开关频率  又因为 uAB 只有+Udc/0 两种状态 因此 pac 也有正/0 两种状态 其中由于 iL 是**正弦增大**（等效平均值）的 pac > 0 的状态也是正弦增大的（离散）

综上所述，可以总结为： PWM 控制开关管的开关 -> 控制电感电流 -> 控制能量流动
（ug 正半周情况）
当 uAB = Udc 时 电感电流正向增大 pac > 0 能量正向流动
当 uAB = 0 时 电感电流负向增大 pac = 0 有功能量不流动
当 uAB = -Udc 时 电感电流负向增大 pac <0 能量负向流动
即在单极性调制下 ug 正半周时 不存在能量负向流动的情况
