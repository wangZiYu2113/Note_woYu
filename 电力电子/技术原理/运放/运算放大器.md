## 1.参数

### 1.输入电压偏移误差 Vos Input Offset Voltage 
运算放大器输出 0 时 所施加的差动输入的电压值
由于芯片内部三极管不完全对称导致的误差 将直接造成输出误差 
Verror = Vos * 闭环增益
改变**电源供电电压** **共模输入电压**将会影响 Vos
大小一般在 uV 级别
### 2.输入偏置电流 IB Input Bias Current
输入电流的算数平均值 即 IB = (IB1 + IB2) / 2
由于内部差分电路正常工作所导致的误差（静态工作点）代表着运放的静态功耗
输入偏置电流经过不对称的外部电阻（输入电阻）将产生压降误差 **直接等效为输入电压偏移误差** 因此两输入端要接等值电阻

CMOS/JFET的 IB 受温度影响较大 温度越高 IB 越大
双极性运放受温度影响不大
其典型值可参考 [[运放的分类]]

### 3.输入失调电流 Ios Input Offset Current
输入电流的差值 即 IB = IB 1 - IB 2
由于内部差分电路不完全对称导致的误差

**降低运放误差的方法**：
综合上述三点 当运放输入为 0 时，输出要考虑 Vos Ib Ios 三点的影响，其中 Ib 通过输入电阻间接影响输出， Vos Ios 是运放内部特性决定
1. 补偿电阻：在同向端串联接地电阻，阻值为反向端输入电阻的大小，一般为 Rf || R1 ，使得同向端反向端输入电阻相同，避免 Ib 引起的输入失调电压
2. 统一减小**分压反馈电阻**和**补偿电阻**的阻值，其值越小，Ios 影响越小，一般取 kΩ 级即可
3. Vos 可通过运放调零引脚减小，但不能解决**温漂**带来的影响

### 4.输入输出限制

#### 1.共模输入电压 Vcm Common Mode Voltage
运放两个输入端电压的平均值 由于运放虚断的特性 输入端电压几乎相同 因此可以认为共模输入电压同时加在两个输入端 
共模输入电压的范围 即输入电压摆幅 Input Voltage Swing
小于或等于供电电压
#### 2.输出电压摆幅 Output Voltage Swing
输出电压的范围 小于或等于供电电压

#### 3.轨到轨输入/输出：
输入输出电压能达到供电电压 输入输出摆幅等于正负电源 其中轨到轨输入更难实现

### 5.输入阻抗 Rin
理想无穷大 ：BJT 数兆欧 CMOS 千兆欧级 几乎不取电流 

### 6.开环增益 Avol Voltage Open Loop 
理想无穷大 单位 dB

### 7.共模抑制比 
差模放大倍数/共模放大倍数 单位 dB
反映运放对差模信号和共模信号的放大能力

### **8.增益带宽积 GBW** 
#### 1.定义
运放的开环增益不是恒定的，而是随着频率变化而变化
当以[[分贝（dB）]]表示开环增益时，其变化是线性的曲线，以每十倍频降 20 dB 的速率降低。即信号频率越高，运放的放大能力越弱。
GBW 即为开环增益 Aol 与频率 f 的乘积（最大值），一般为数 MHz 级，高速运放可达数百 MHz
#### 2.应用
当开环增益衰减到 1 时对应的频率即为**单位增益带宽**
**GBW 有效条件**：
1. 引入负反馈
2. 工作在小信号区域，不被 SR 限制
#### 3.性能
1. 一般来说，GBW 与静态电流 Iq 呈正相关，Iq 越大，GBW 越大
2. 补偿型运放主极点极低，通常为几十到几百 Hz ，从而使 GBW 为常数，而高速运放或特殊运放则不符合此规律，其 GBW 有更多的规定

### 9.静态电流 Iq
运放供电端的电流 通常为 mA / uA 级 决定整体运放的功耗


## 2.工作原理

### 1.开环状态

核心公式：$Vout = Aol × (Vin+ - Vin-)$
Aol 开环增益 理想→∞
因此，开环状态下，Vin+ 与 Vin- 的差值极小，只有这样输出电压才能在运放供电电压范围之内，保持在**线性区**，而一旦出现差模扰动使得差值变大，输出电压就将超出电压极限，运放进入**饱和区**。所以开环状态是极其不稳定的，因此引入闭环控制，即负反馈。
通过反馈，使得无限大、不可控的开环增益变换为可控的、稳定的闭环增益

### 2.闭环状态
负反馈：将输出电压反馈至反向端（-） 抑制输出变化 降低增益
正反馈：将输出电压反馈至同相端（+） 激发输出变化 增大增益
#### 1.核心公式
$β = Vout ​/ Vfb ​​= ( R1​+ Rf ​) / R1​​$   **β 反馈系数** 
Acl​ = Aol / ​(1+Aol\*​β)    ​         **Acl 闭环增益**
Aol ​β = Aol\*β                        **Aol ​β**  **环路增益**
1. 当开环增益 Aol 无限大时，闭环增益可简化为  1/ β
2. 当高频放大时，Aol 不可看作无限大，此时 当Aol\* β << 1 时，Acl = Aol，即闭环增益与开环增益相同

### 3.虚短与虚断

**虚断**：是运放自身特性所决定的，由于输入电阻无穷大，输入输出电流几乎为零，因此虚断任何时间的成立
**虚短**：指两个输入端的电压相等，Vin- = Vin+，成立条件有两点：
- 运放工作在深度负反馈状态 AF >> 1
- 运放工作在放大区
显然，当运放开环状态时，输出很容易达到极限，即工作在非线性区，因此不符合虚短。可以理解为即使输出端电压差很大，输出依然是极限电压
当满足虚短条件时，Vout 有界
