### 2. 电容的作用：<mark class="hltr-cyan">储能缓冲</mark>
在输入输出功率不同时，电容作为储能器件平衡功率，使**电压**变化平缓。典型应用有直流母线并联的大容量的电解电容。
1. 由电容两端电压电流关系可知 电容两端电压不能突变 电流可以突变 
当功率突然发生变化时 电容两端电压会缓慢变化 （充电或放电过程）
典型应用：突然上电或突然掉电，负载突变
2. 参数：储能电容不是越大越好，容量过大会带来的问题有：浪涌电流过大 成本增大 控制迟钝
还要注意电容的耐压值和寿命，耐压至少要留足 1.5-2 倍裕量
**P = Irms² × ESR** 选择低 ESR 的电容 减少因纹波产生的发热 尤其是母线电容 一般纹波会较大
3.   为什么电容过大会导致浪涌电流过大？
**Q = C × V** 上电时 电压突然增大 电容越大 充入的电荷越多 **i = dQ/dt** 就会导致瞬时电流增大
**ΔU ≈ ΔQ/C + ΔI × ESR** 同时由于此式  C 越大 纹波电压越小 要在两者之间平衡 选择合适的电容
4. 电容的寿命问题：和电容的发热有关
### 3.电容的作用：<mark class="hltr-cyan">交流旁路/滤波/去耦</mark>
本质：电容对交流旁路呈低阻抗，为交流通路提供额外的回路，也就是隔直通交
1. 典型应用：
输入滤波：防止高频噪声回到电源侧
输出滤波：降低输出**电压**的纹波
**高频去耦**：主要放在高频器件附近 为高频信号提供回路 要注意靠近开关器件使回路尽量短 
LLC RC 滤波、XY 电容等
2. 靠近高频器件的原因：功率器件开关时 电流会在很短时间内变化 高频电流需要就近从电容获得或回到电容 如果电容离器件较远 中间经过的导线、引脚等会形成寄生电感 由于
 **Δu = L× di/dt** 而电流变化很快 因此会产生极大的**电压尖峰** 同时尖峰还会附带**振铃**
 这也印证了去耦电容要选择低 ESL 
 ESL 低 电容等效电感越小 自谐振频率越高 同样情况下 对于高频噪声的阻抗越小 去耦效果越好 同时也可以避免电压尖峰的产生
3. 振铃：开关尖峰后产生的一串高频衰减震荡 通过引入阻尼可避免或加速振铃的衰减 
4. 多颗大小电容并联的意义：降低 ESR     增大容量（小电容容量小） 降低 ESL     分担纹波电流     扩展滤波频段 改善瞬态响应（大电容响应慢）
